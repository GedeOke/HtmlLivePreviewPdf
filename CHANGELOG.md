# Changelog

## 0.1.0

- Initial internal release.
- Live PDF preview for local HTML, JavaScript, CSS, assets, and API-backed content.
- PDF.js viewer with navigation, zoom, fit-width, refresh, and manual export.
- Actual paper-size information plus mouse-wheel and touchpad pinch zoom.
- Platform-specific bundled Chromium builds for Windows x64 and macOS x64/arm64.
